## Reglas para retomar

1. Cada tarea debe crear el evento siguiendo `TEMPLATE.md` (frontmatter completo, wikilinks, fuentes inline).
2. **Fuentes:** mínimo 2 por evento, de medios distintos, URL verificada (status 200), nunca redes sociales como fuente única.
3. Los eventos de 2019-2021 (era Piñera) necesitan entidades nuevas en `entities.yaml` (personas: Piñera, Cubillos, Briones; orgs: INDH, Convención Constitucional, etc.).
4. Después de cada tanda: `npm run build` + `npm run generate-index` + verificar 0 fuentes huérfanas.
5. Actualizar esta bitácora: mover la entrada a `✅ hecho` y registrar el ID del evento creado.
